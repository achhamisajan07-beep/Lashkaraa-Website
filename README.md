# Lashkaraa Landing Page

A responsive HTML and CSS storefront landing page inspired by Lashkaraa's campaign homepage.

## Run locally

Open `index.html` in a browser, or start a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The hero video and its poster image are included in the `video` and `image` folders. Collection and product photography loads from Unsplash.
